# Product Overview

**Muslim Dhikr App** is a cross-platform application (Android, iOS, and Web) that gives Muslims access to authentic adhkar (remembrances and supplications) sourced exclusively from the Qur'an and Hadiths graded Sahih or Hasan by recognized scholars, following the methodology of the Salaf us-Salih.

## Core Purpose

- Provide a structured, trustworthy library of adhkar with full source references and authenticity grades
- Guide users through timed/counted dhikr sessions by category
- Work fully offline on all platforms

## Key Features

- **Dhikr Content Library** — Arabic text, transliteration, translation, source reference, authenticity grade, and prescribed repetition count for every entry
- **Categories** — Morning, Evening, After Prayer, Before Sleep, Waking Up, Entering/Leaving Home, Eating, General Remembrance (and more)
- **Guided Sessions** — step-by-step session flow with a tap counter that tracks repetitions
- **Source Transparency** — expandable view showing full Hadith/Qur'anic context and scholar grading
- **Favorites & Search** — bookmark adhkar and search by Arabic, transliteration, or translation
- **Localization** — English default; UI and translations adapt to the user's selected language; Arabic always rendered in Arabic script (RTL)
- **Accessibility** — adjustable text size (Small / Medium / Large), persisted across sessions
- **PWA / Offline** — service worker caches all assets and the content database on first load; installable to home screen

## Target Platforms

| Platform | Minimum Version |
|----------|----------------|
| Android  | API 26 (Android 8.0) |
| iOS      | 14+ |
| Web      | Chrome, Firefox, Safari, Edge (latest 2 major versions) |

## Content Rules (Non-Negotiable)

- Only Sahih or Hasan graded Hadiths are included — Da'if or weaker are excluded
- Every dhikr must have a Source Reference (Surah:Ayah or collection/book/hadith number)
- No user account or login required to access any content
